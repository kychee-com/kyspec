# Lantern principles

Numbered so specs and changes cite them (`principles #2`).

1. **The list belongs to its reader.** Export always works, in a format another tool reads,
   and nothing in the product depends on the reader staying.
2. **Nothing is deleted.** A book leaves the list by being archived; its notes stay, and it can
   come back.
3. **The API is the product.** The page is one client. Every action the page offers is one
   documented request, and anything the page can do, a script can do.
